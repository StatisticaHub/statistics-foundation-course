# Exercises

This section contains theory-focused exercises.

The exercises are designed to test conceptual understanding, mathematical reasoning, interpretation, and derivation skills.

No coding is used.

---

## Exercise format

Each exercise page may include:

1. Definition questions.
2. Conceptual questions.
3. Mathematical questions.
4. Derivation questions.
5. Interpretation questions.
6. Short applied scenarios.
